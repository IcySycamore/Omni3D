# 上下文 + 术语表

## 一、上下文（为什么重写、边界在哪、分几步）

### 1.1 一句话

Python 参考实现 **`v1.0.0-mvp`** 已冻结并归档：功能完整（316 项测试全绿、三端口可部署、
官网含账号与计量计费），但**后续开发换成 C# / .NET + Vue**，本仓从此只作参考实现。

### 1.2 真正的动机（别记错）

**组织约束**：长期只维护**一门后端语言**。
**不是**"Python 慢"或"Python 不安全"——HTTP 层从来不是瓶颈（瓶颈是 GPU 前向，秒级），
安全风险也都在**协议与部署**（token 进 query、裸 `{error}`、CORS `*`、密钥散落），换语言不会自动消失。

### 1.3 现状边界（哪些东西必须复现，哪些可以扔）

| 类别                     | 内容                                                                                                    | 重写时的态度 |
| ------------------------ | ------------------------------------------------------------------------------------------------------- | ------------ | -------------------------------------------------------------------------------------- | ---------------------------------------------- |
| **必须复现**（产品承诺） | 上传/结果字段口径、PLY 格式（float64 小端）、会话层 owner 隔离与幂等整体替换、面积=                     | AB×AC        | / 体积=\|det\|、未标定 `u/u²/u³` → 标定 `m`、SOR 默认开、local head 默认、224 只能预览 | 逐条对照 [`../HANDOVER.md`](../HANDOVER.md) §3 |
| **可以扔**（实现债）     | 进程内内存任务队列 + 轮询、单文件 9.5k 行前端、CDN 依赖、shared-SQLite 跨进程假设、multipart 一次性上传 | 见各自 ADR   |
| **明确不做**             | 支付网关（验证阶段全免费）、App/AR 生态（`qt_app/`）、训练/微调                                         | 范围外       |

### 1.4 两步计划（**panel 先，服务后**）

```
阶段一  panel（前端）                阶段二  服务（后端）
──────────────────────              ──────────────────────
Vite+TS+Vue3+three.js               C#/.NET：控制面 → 网关 → 几何/产物 → worker 化
线协议（02）的客户端半边             线协议的服务端半边（先转发 Python worker）
后端用 mock（合成点云/伪造进度）      推理仍由 Python worker 兜住（ADR-0003）
出口：全流程在无 GPU 下跑通并测完     出口：panel 不改一行即可接真服务
```

**为什么 panel 先**：① panel 是用户唯一摸得到的产品表面；② 它的契约（线协议）一旦定下来，
服务端就是"照实现"；③ 用 mock 可以完全并行、不受 GPU/权重/队列进展影响。

### 1.5 当前可用的真实起点（别重复造）

- 参考实现里的 mock 服务：`web/mock_server.py`（旧协议形状，可作改写起点）；
- 冻结的行为契约与精度基线：[`../HANDOVER.md`](../HANDOVER.md)；
- 同类产品对比与"该抄什么"：[`../RELATED-WORK.md`](../RELATED-WORK.md) 与 [`01-industry-research.md`](01-industry-research.md)；
- 线协议提案：[`02-wire-protocol.md`](02-wire-protocol.md)。

## 二、术语表（新仓库通用；只收"必须叫法一致"的词）

| 术语                             | 定义（一句话）                                                         | 备注                    |
| -------------------------------- | ---------------------------------------------------------------------- | ----------------------- |
| **panel（面板）**                | 用户干活的**前端**：采集 → 提交 → 查看 → 测量 → 标注 → 历史 → 设置     | 阶段一做它              |
| **service / provider（服务商）** | 跑重建的**数据面**服务：任务、会话、点云、测量                         | 客户可自建              |
| **portal（官网）**               | **控制面**服务：账号、计费、发 API Key、流水                           | 官方才有                |
| **采集（capture）**              | 拿到输入帧：录制 / 连拍 / 本地文件 / AR 扫描                           | 四者互斥                |
| **task（任务）**                 | 一次重建请求；`task_id` **就是** `session_id`                          | 幂等锚点                |
| **session（会话）**              | 任务的持久形态：历史、标注、尺度都挂在它下面                           | 按 owner 隔离           |
| **owner**                        | 数据归属键：`user:<name>`（登录/Key）或 `anon:<client_id>`（匿名）     | 隔离靠它                |
| **artifact（产物）**             | 任务的输出文件：`pointcloud.ply` / `tileset.json` / `scene.copc.laz`   | 预签名 URL 交付         |
| **chunk / tile（分块/瓦片）**    | 点云的 LOD 单元：八叉树/3D Tiles 的一个节点                            | 流式渲染靠它            |
| **origin（局部原点）**           | 渲染坐标要减掉的那个中心点（否则 float32 精度不足）                    | 线协议 §5 的坑          |
| **帧（frame）**                  | 从视频/AR 里抽出来的一幅图；`frames` 是任务输入单位                    | 默认 16                 |
| **resolution**                   | 推理分辨率：`512`（默认，可测量）/ `224`（**被裁成正方形，只可预览**） | 产品红线                |
| **SOR**                          | 统计离群点剔除：`k`/`std`，任一为 0 即关闭                             | 默认开                  |
| **local head / global head**     | 点云取哪一路输出；默认 **local**（对齐上游评测口径）                   | 两档共享坐标系          |
| **scale（尺度）**                | 模型坐标 → 米 的因子；两条路径：AR 米制对齐 / 两点标尺反推             | 服务端是唯一真相        |
| **AR 桥**                        | App 壳在本机起的 HTTP 桥（`:50687`），给网页原生能力                   | 范围外                  |
| **API Key**                      | 官网签发的长期凭据（`omni3d_…`），库里只存 sha256                      | `Authorization: Bearer` |
| **credential（凭据）**           | panel 里"某台服务商"的登录态：`{token, username, apiKey}`              | **按服务商分开存**      |
| **metric（计量）**               | 计费口径：`points` / `voxels` / `mesh`                                 | 单价见下                |
| **plan pack（计划包）**          | 包月调用额度（Personal 100 / Professional 600），**30 天重置**         | 优先扣                  |
| **usage pack（用量包）**         | 预付折扣包（100 万单位），**不过期**、**各包独立**                     | 次优先                  |
| **balance（余额）**              | 按量兜底的钱（分）；充值档 $5/10/20/50                                 | 最后扣                  |
| **charge（扣减）**               | 唯一扣减入口：**计划包 → 用量包 → 余额**                               | 每步写流水              |
| **ledger（流水）**               | 一切金额变动 + 余额快照                                                | 对账依据                |
| **arrears（欠费）**              | 后付费下"算完了但付不起"的状态；产物扣押、提交 403                     | 见 ADR-0005             |
| **problem+json**                 | RFC 9457 错误体；`code` 为稳定机器码                                   | 线协议 §6               |
| **Idempotency-Key**              | 写操作幂等键（24h）；同 key 返回同一资源                               | 防重复烧 GPU            |

### 单价与额度（冻结口径，新仓库照抄常量）

- 点云 `200 点 = 1 分`；体素 `1,000 = 1 分`；网格 `1,000 三角面 = 1 分`；
- 计划包：Personal `$8.99`/100 次、Professional `$18.99`/600 次（30 天重置）；
- 用量包：每种计量 100 万单位，预付 **9 折**（点云 $45 / 体素 $9 / 网格 $9），不过期；
- 充值档：`$5 / $10 / $20 / $50`；
- 验证阶段 `BETA_FREE`：额度免费发放，**包照扣、余额不扣、额度不足也不拦**。
