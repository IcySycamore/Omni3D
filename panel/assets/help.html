帮助文档

采集视频

三种方式：点「录制」用摄像头录一段视频（需浏览器授权，推荐 Chrome / Edge）； 点「拍摄」连拍多张不同角度的照片；点「本地视频」选已有文件。采集完点「提交重建」。

拍摄建议：围绕物体缓慢匀速走一圈，距离 30~60cm，录 10~20 秒， 各个角度都拍到。不要快速晃动，避免强烈反光。

AR 扫描（真实尺度）

AR 扫描要在 Omni3D App 里用。点「AR 扫描」会打开 App 的原生扫描页， 页面实时显示帧数；扫完自动替换视频输入，重建结果自带真实尺度。

启动重建

视频或图片就绪后点「提交重建」，进度条显示当前阶段与百分比，完成后自动跳到建模结果页。

视角数量

该配置项的可用性由您的服务商给出

  • 视角越少，重建越快，适合快速预览。
  • 视角越多、重建更精细，耗时越多。

抽帧速度

「视角数量」单位时间内对视频进行均匀抽帧的数量：视频按这个数字均匀抽帧，再交给模型估位姿。 帧越多越慢、覆盖越全。拍摄时移动较慢时可以适当调小。

相机参数

包含位姿，尺度，相机内外参等信息。部分机型支持

建模结果 · 视图操作

  • 旋转：左键拖动 / 单指滑动。
  • 缩放：滚轮 / 双指捏合。
  • 平移：中键或右键拖动 / 双指拖动或使用工具栏的「移动」
  • 滚转：双指扭转或在设置里为旋转键设置键位。
  • 万向轴（三环）：右下角显示当前姿态控制组件
  • 重置视角：工具栏的「重置视角」把点云放回画面中央。

建模结果 · 测量

  • 选择（默认工具）：点已有元素 = 选中它；点云上的点 = 生成一个「点」元素并选中， 可以拿去量长度、量面积；点空白 = 取消选择。按住 Ctrl/⌘ 点多选。
  • 框选：按住左键拖出矩形，框内的点云点会收成一个「框选点组」（一次最多 1000 个点）， 矩形内已有的元素也会被选中。
  • 移动：按住左键拖动平移画面，只挪视角，不选点。
  • 量长度：点「长度」后在点云上依次点两个点。也可以先在「选择」下点出两个点， 工具亮起后点「应用」。
  • 量面积 / 体积：沿物体边缘依次点它的各个顶点。面积每点一个会自动与上一个顶点连成线， 体积只收点、不连线。面积至少 3 个顶点、体积至少 4 个；够了状态栏就显示数值，之后每加一个顶点都会更新。 也可以先在元素列表里勾选好顶点，再点面积 / 体积，会自动排成环形。 两者量的都是凸的形状，凹进去的部分会被补上，所以量凹陷形状会偏大。
  • 面积的测量平面：前三个顶点定出一个平面，视图里半透明的那块就是被测的面。 后面每个顶点都落在这个平面上：点偏了会提示一声，并按平面上的对应位置落点。 撤销（Ctrl+Z）删掉顶点后，平面按剩下的前三点重算。
  • 完成：顶点够数后点状态栏的「完成」。面积会自动收口围成一圈，每个顶点最多连两条线， 所以连不出分叉；体积没有环，直接按凸包算。体积那 4 个点要是都挤在同一个面上，体积就是 0。
  • 尺度（反向尺度推导）：点两个点，在弹窗里填这两点的真实长度， 之后所有测量都按真实尺寸显示。

测量尺度原理

没标定前显示 u / u² / u³（任意单位），标定后按真实尺寸显示。长度 = 两点距离； 面积 = 所选顶点围成的凸多边形面积；体积 = 所选顶点围成的凸包体积。

常见物品尺度（标定参考）

标定要拿一个已知真实长度的东西。手边有卡片、A4 纸的优先用；量的时候取边缘到边缘， 短边方向更容易对齐。实际尺寸以手边实物为准。

  • A4 纸长边：297 mm（短边 210 mm，对角 363.7 mm）。
  • 银行卡 / 信用卡长边：85.6 mm（ISO/IEC 7810 ID-1，短边 53.98 mm）。
  • 1 元硬币直径：25 mm。
  • 乒乓球直径：40 mm。
  • CD / DVD 光盘直径：120 mm。
  • 标准砖长边：240 mm（240 × 115 × 53 mm）。

建模结果 · 元素与信息

级联规则（设置 → 行为 → 元素视图）：删掉一个顶点，引用它的测量一定跟着删。 少了顶点的测量算不出东西，所以这条不是可选项。可选的是另外三条： 选中父元素时级联选中子元素（默认关）、删除父元素时级联删除子元素（默认关）、 测量完成时折叠子元素（默认开）。

  • 元素视图：列出所有已标注的元素，每条可勾选、可单独删除。
    选中：点整行 = 单选；Ctrl/⌘ 点行，或勾复选框 = 多选。
    右键菜单：全选 / 全不选 / 反选 / 清空元素。
    顶部实时显示「共 N 元素，选中 M」。
  • 全局属性：本次重建的视角数量、输入质量、点云点数、耗时与标定尺度。
  • 导出：把当前点云导出为 PLY 文件。
  • 快捷键：工具与常用命令都有快捷键（默认 1–7 切工具），可在「设置 → 快捷键」里改。

服务商与 API Key

一台服务商 = 一个地址 + 可选端口 + 一个 API Key，在「设置 → 服务」里配，每台各存一份。 API Key 在官网注册后领取，推广页有入口；模型列表由服务商在验证 Key 时回传。

要不要 Key 由服务商自己决定：自用的本地实例可以留空，对外提供服务的实例要求填 Key， 从本机访问也一样。校验发生在每次点「提交重建」的那一刻，请求照常发出去， 由服务商回的状态码说了算：401/403 就是认证没过，没填 Key 或 Key 不对。

左下角的灯只看真实提交的结果：灰「未知」= 还没测过，绿「已连接」= 提交成功过， 红「错误」= 提交失败过（认证被拒、连不上、服务端报错都算）。换服务商或改了 Key 就回到灰， 具体是哪一种失败，提示文案里会写明。

历史记录

你重建过的模型：点「查看」把点云与标注加载到建模结果页，点「删除」移除该条，处理中的任务不能删。

AR支持

在 App 内打开本页才能用 AR 扫描与真实尺度。桌面端 / 手机 App 在「设置 → 服务」里指定服务器地址。

AR 桥是 Omni3D App 在本机起的服务（127.0.0.1:50687），只服务本机浏览器， 负责原生相机采集与位姿上报。不经过 App、直接用浏览器打开本页，只能做普通重建，没有真实尺度。

关于

Omni3D 把一段视频、一组照片或一次 AR 扫描重建成可测量的点云：浏览器负责采集与交互， 重建在服务商（本机或远端）完成。验证阶段免费使用。
