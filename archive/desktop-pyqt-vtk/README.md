# 归档：PyQt5 + VTK 桌面客户端

**状态：已废弃（2026-09），不再维护、不再提供启动入口。**

## 为什么废弃

仓库原有两个客户端实现：网页端（JS）与桌面端（Python + PyQt5 + VTK）。两套实现意味着
几何、测量、交互逻辑必须写两遍，而「共享核心」在 Python 与 JS 之间**无法字面复用**。
移动端 App 本来就是网页的 WebView 壳，桌面端再单独维护一套得不偿失，因此决定
**收敛为单一 web 客户端**：

```
浏览器 ─┐
        ├──► web/index.html（唯一客户端实现）──► server
安卓 App ┘   （WebView 壳 + 本地桥 :50687）
```

替代方案「一套 Qt 跨平台打所有链路」也已评估并**否决**：**VTK 没有 Android 支持**——
桌面只能用 VTK、移动只能 QtQuick3D，仍然是两套渲染代码；而且要废弃已高度完善的 web client，
并重走一遍此前踩过的 Qt 移动端坑（`ImageReader maxImages` 崩溃、`QtWebView` 恒在 QML 表面之上、
Qt 6.5 无 `PointsGeometry`、`QtWebView` 大概率不支持 `getUserMedia`）。

## 已迁移到网页端的能力

| 原桌面端能力                    | 现在在哪                                                 |
| ------------------------------- | -------------------------------------------------------- |
| 注册 / 登录 / 登出（挑战-应答） | 网页账号页（协议与服务器完全一致）                       |
| 会话过期处理                    | 网页 `fetch` 拦截器：同源 401 → 全局登出并提示重登       |
| 服务器地址配置                  | 网页与服务器**同源**，无需配置；移动端 App 在顶部 ⚙ 里改 |
| 提交重建 + 实时进度             | 网页采集页（`POST /api/tasks` + 轮询）                   |
| 3D 点云查看                     | 网页 three.js（VTK → three.js）                          |
| 两点测距 / 标尺校准             | 网页测量功能                                             |
| 历史：列表 / 加载 / 删除        | 网页历史页（`/api/history`，按 `owner` 隔离）            |
| PLY 下载                        | 网页「⬇ 下载 PLY」（`/api/history/{id}/ply`）            |
| 匿名记录并入账号                | 网页账号页（手动确认）                                   |

## 仍然可复用的部分

- `api_client.py` —— 独立于服务器实现的**认证协议参考实现**（`verifier` / `proof` 的拼接顺序），
  需要交叉验证协议时可以对照它
- `ui/theme.py` 的 QSS 主题（若将来重做 Qt 界面）
- `login_window.py` 的无边框窗 + 拖拽 + ⚙ / ─ / ✕ 标题栏处理
- `vtk_view.py` 的拾取思路（射线最近点 → 已被网页端的「射线候选 + 屏幕邻近 + 全量吸附」取代）

## 重要提示

**本目录代码不再接受修改。** 后续所有客户端工作都在 `web/index.html` 进行。
归档前的完整历史见 git 中的 `desktop/` 路径（可加 `--follow` 追溯重命名）。
