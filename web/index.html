帮助

采集视频

三种方式：① 点「● 录制」用摄像头录视频（需浏览器授权，推荐 Chrome/Edge）；② 点「📷 拍摄」拍照，可连拍多张不同角度，提交时走图片模式；③ 点「本地视频」从设备里选文件。采集完成后点「提交重建」。

拍摄建议：围绕物体缓慢匀速移动，距离约 30~60cm，录 10~20 秒，覆盖各个角度；避免快速晃动和强烈反光。

AR 扫描（真实尺度）

AR 扫描需要在 Omni3D App 内使用。点「AR 扫描」后 App 会打开原生扫描页自动采集，页面实时显示帧数。扫描完成会自动替换视频输入，重建结果自带真实尺度。

启动重建

确认视频/图片就绪后点「提交重建」，进度条会显示当前阶段与百分比，完成后自动跳到建模结果页。

视角数量

  • 8 个：最快，适合快速预览。
  • 12 个：速度与质量平衡。
  • 16 个（默认）：视角更多，重建更精细但更慢。

抽帧速度

「视角数量」就是抽帧数量：视频按这个数字均匀抽帧，再交给模型估位姿。帧越多越慢、覆盖越全；如果拍摄时移动得太慢、相邻帧几乎一样，可以适当调小。

相机参数

普通视频没有真实位姿，重建出来的是一份「形状对、尺度任意」的点云；AR 扫描会带回相机内外参，结果自带真实尺度。面板不展示矩阵，只在结果页的全局属性里给出这次的视角数量与标定尺度。

建模结果 · 视图操作

  • 旋转：左键拖动 / 单指滑动。
  • 缩放：滚轮 / 双指捏合。
  • 平移：中键或右键拖动 / 双指拖动；也可以用工具栏的「移动」（小手）左键拖。
  • 滚转：双指扭转；也可以在设置里给旋转键绑键位。
  • 万向轴：右下角的方向棱镜显示当前姿态：抓住某条圈拖动就只绕那条轴旋转（抓不到圈不响应）。不需要时可以从工具栏关掉。
  • 重置视角：工具栏的 ⤾ ，把点云重新放到画面中央。

建模结果 · 测量

  • 选择：点工具栏的选择（默认就是它）：点已有元素 = 选中它；点云上的点 = 选中那个点（会生成一个「点」元素，可以拿去画线/量面积）；点空白 = 取消选择。Ctrl/⌘ 点多选。
  • 框选：点工具栏的框选，按住左键拖出矩形：框内的点云点会收成一个「框选点组」（一次最多 1000 个点，在元素视图里就是一行），矩形内已有的元素也会被选中。
  • 移动：点工具栏的移动（小手），按住左键拖 = 平移画面，专用来挪动视角而不选点。
  • 量长度 / 面积 / 体积：先在画面里选好需要的点数（画线 2 个、面积 3 个、体积 4 个），对应工具会亮起，点「应用」即可；也可以直接切换工具后在点云上依次点击落点。
  • 尺度（反向尺度推导）：选 2 个点，在弹窗里填这两点的真实长度，之后所有测量都按真实尺寸显示。

测量尺度原理

没标定前显示的是 u / u² / u³（任意单位），标定后按真实尺寸显示。长度 = 两点距离；面积 = |AB × AC|（两向量张成的平行四边形，恰好是三角形面积的 2 倍）；体积 = |det[AB, AC, AD]|（平行六面体）。工具栏的三角形面积同理，选 3 个点就行。

建模结果 · 元素与信息

  • 元素视图：列出所有已标注的元素；每条可勾选、可单独删除（删除某个点会连带删除引用它的测量）。
  • 全局属性：显示本次重建的视角数量、输入质量、点云点数、耗时与标定尺度。
  • 导出：把当前点云导出为 PLY 文件。
  • 快捷键：工具与常用命令都有快捷键（默认 1–7 切工具），全部可在「设置 → 快捷键」里改。

服务商与 API Key

一台服务商 = 一个地址 + 可选端口 + 一个 API Key（在「设置 → 服务」里配，每台各存一份，不共用账号）。API Key 在官网注册后领取（推广页有入口），模型列表由服务商在验证 Key 时回传。左下角的灯：亮 = 身份验证通过且模型就绪，灰 = 未验证，红 = 凭据无效。

历史记录

你重建过的模型：点「查看」把点云与标注加载到建模结果页，点「删除」移除该条（处理中的任务不能删）。

AR支持

在 App 内打开本页即可使用 AR 扫描与真实尺度。桌面端 / 手机 App 在「设置 → 服务」里指定服务器地址。

AR 桥是 Omni3D App 在本机起的服务（127.0.0.1:50687），只服务本机浏览器：它提供原生相机采集与位姿上报，所以直接用浏览器打开本页（不经过 App）只能做普通重建，没有真实尺度。

关于

Omni3D 把一段视频（或一组照片、一次 AR 扫描）重建成可测量的点云：浏览器负责采集与交互，重建在服务商（本机或远端）完成。验证阶段免费使用。
