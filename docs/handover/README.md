## 两步走的边界（重要）

**阶段一：panel（前端先行）**

- 只做客户端：TS + Vite + Vue 3 + three.js；线协议按 `02-wire-protocol.md` 实现**客户端半边**；
- 后端用 **mock 服务**顶上（参考实现里已有 `web/mock_server.py`，按新线协议重写一个更省事）；
- 出口：panel 在 mock 上完成采集 → 提交 → 进度 → 3D 查看 → 测量 → 标注 → 历史的**全流程**，
  且**不依赖任何真实模型**；线协议在客户端侧定型并被测试固化。

**阶段二：服务（后端跟进）**

- 按 `02-wire-protocol.md` 实现**服务端半边**，先用 Python worker 兜住推理（ADR-0003）；
- 再按 ADR 顺序做：控制面 → 网关 → 几何/产物 → worker 化 → 前端接真服务。
