# Omni3D 用户使用手册

## 1. 文档目的

本手册面向使用 Omni3D 网页端完成三维重建的普通用户，说明如何采集素材、提交任务、查看点云和导出结果。

> 管理员负责部署服务、发放 API Key、维护账号与处理异常；普通用户不需要登录服务器，也不需要安装 Python、CUDA 或 Docker。

## 2. 使用前准备

1. 使用最新版 Chrome、Edge 或移动端 App 打开管理员提供的 Omni3D 地址；
2. 向管理员领取可用的 API Key；
3. 在“设置 → 服务”中填写服务地址和 API Key，并完成验证；
4. 确保网络稳定，避免上传或重建过程中关闭页面。

API Key 是服务凭据，请勿发送到群聊、截图、公开文档或代码仓库。若怀疑泄露，应联系管理员吊销并重新创建。

## 3. 素材采集建议

重建质量首先取决于输入素材。建议：

- 围绕目标物体缓慢移动拍摄约 10～20 秒，尽量覆盖正面、侧面、背面和顶部；
- 保持光线均匀，避免强反光、逆光、运动模糊和剧烈明暗变化；
- 尽量让目标物体始终位于画面中央，避免被人或其他物体长时间遮挡；
- 对无纹理、透明、反光或快速运动物体，重建效果可能下降；
- 上传个人、涉密或未经授权的数据前，应先确认数据使用权限。

可使用网页录制、拍照、本地视频或本地图片。移动端 App 的 AR 扫描还可提供米制位姿与尺度信息。

## 4. 推荐设置

在“设置 → 采集”中选择参数。

| 项目 | 推荐值 | 说明 |
| --- | --- | --- |
| 重建分辨率 | `512 · 完整画幅` | 推荐用于正式重建和测量。 |
| 预览分辨率 | `224 · 仅预览` | 仅用于快速试跑；会裁切为方形，不应用于测量。 |
| 视角数量 | 以页面可选最大值为准 | 视角越多通常覆盖越完整，但耗时和显存占用更高。 |
| AR 扫描分辨率 | 选择设备支持的最高档 | 仅在移动端 AR 扫描场景生效。 |

服务器会根据 GPU 显存动态限制可选视角数。例如显存约 24 GB 以下的设备可能最多显示 16 个视角；这不是页面故障，而是为了避免重建过程中显存不足。

## 5. 提交一次重建

1. 在左侧选择“采集”；
2. 选择“录制”“拍摄”“本地视频”或图片上传；
3. 确认素材已显示为“已就绪”；
4. 检查设置中的分辨率、视角数和 API Key；
5. 单击“提交重建”；
6. 等待任务经历排队、抽帧、推理、生成结果等阶段。

重建耗时受 GPU 性能、排队情况、分辨率、视角数量和输入素材影响。任务运行期间请勿停止服务器；刷新页面后，可在“历史记录”中查看已持久化的任务。

## 6. 查看与导出结果

重建完成后，在“建模结果”或“历史记录”中打开任务：

- 使用鼠标/触控操作旋转、缩放和移动点云；
- 使用测量工具选择点位并查看距离、面积或体积；
- 未进行尺度校准时，数值使用相对单位；网页端可通过标尺校准获得真实尺度；
- 单击“下载 PLY”导出完整点云，可用 MeshLab、CloudCompare 或 Blender 打开；
- 确认不再需要的记录可从历史中删除。

页面渲染的是为流畅显示而抽样后的点云；下载的 PLY 为完整结果，文件体积通常更大。

## 7. 常见问题

### 提示“认证失败”或无法提交

进入“设置 → 服务”，检查服务地址和 API Key 是否正确；API Key 失效、被吊销或复制时漏字都会导致认证失败。不要尝试把 Key 粘贴到公开页面或聊天记录中。

### 页面能打开，但重建任务失败

先确认服务状态正常；若提示模型未就绪，等待服务器加载模型后重试。若持续失败，请将任务时间、错误提示和输入类型告知管理员，**不要**发送 API Key。

### 为什么没有 24 个视角选项

可选视角由服务端 GPU 显存决定。当前设备未显示的选项表示该档位不适合当前资源，选择页面可见的最高档即可。

### 为什么停止服务器后网页不可用

网页、任务队列和 GPU 推理均运行在服务器上。服务器停止后，网页请求和重建任务都会中断；启动后需等待服务和模型恢复就绪。

## 8. 获取支持

联系项目管理员时，请提供：访问时间、所用设备/浏览器、操作步骤、错误提示、任务编号（若有）和是否能复现。请勿提供密码、SSH 私钥或完整 API Key。
