# 重建速度与质量（实测）

> 复现：`.\run.ps1 bench`（全部示例）或
> `.\run.ps1 bench --frames 4 8 12 --res 224 512 --repeat 3`
>
> 脚本：`scripts/bench_reconstruct.py`

## 测量环境

| 项   | 值                                                              |
| ---- | --------------------------------------------------------------- |
| GPU  | 本机 CUDA（`torch.cuda.is_available() == True`）                |
| 模型 | Fast3R ViT-Large（`jedyang97/Fast3R_ViT_Large_512`）            |
| 数据 | `demo_examples/` 5 个示例视频，`cv2` 均匀抽帧                   |
| 口径 | 每次 warmup 1 次后计 1 次；耗时含抽帧后**加载→推理→对齐**全流程 |
| 版本 | torch 2.5.1+cu121                                               |

## 速度

**结论：`512px` 约 0.17 s/帧，`224px` 约 0.05 s/帧（约 3.4× 差距）。**

按分辨率的中位数（n=15）：

| 分辨率 | 每帧耗时（中位） | 12 帧端到端 |
| ------ | ---------------: | ----------: |
| 224    |    **0.05 s/帧** | 0.5 ~ 0.9 s |
| 512    |    **0.17 s/帧** | 2.0 ~ 3.5 s |

## 质量（**代理指标**，非绝对精度）

⚠️ 本机**没有 GT 点云/位姿数据集**，因此下面衡量的是**自洽性与稳定性**，
不能等同于绝对精度。绝对精度需跑 vendored 的 `fast3r/eval/`
（依赖 re10k / robustmvd 数据集，本机未附）。

| 指标              | 含义                                                       | 理想                   |
| ----------------- | ---------------------------------------------------------- | ---------------------- |
| `residual_ratio`  | local head 与 global head 对齐后的残差 RMS ÷ 点的 RMS 半径 | 越小越自洽             |
| `local_scale_std` | 各视图 local→global 拟合缩放的离散度                       | 越小越一致             |
| `mean_conf`       | 模型 global head 的平均置信度                              | 仅作参考，跨场景不可比 |

观测（30 组）：

- `residual_ratio` 中位 **0.0251**，范围 **0.0100 ~ 0.0981**
- 最好：`kitchen`（残差 0.010、尺度离散 0.0012、置信度 17.3）
- 最差：`family`（4 帧 224 时残差 0.096）、`lighthouse`（尺度离散 0.066~0.078 最高）
- 分辨率提升会明显改善自洽性：例如 `family` 4 帧 224→512，残差 0.096→0.044；
  12 帧 512 时残差降到 0.028

## 实践建议

| 场景                            | 建议                                                      |
| ------------------------------- | --------------------------------------------------------- |
| 快速预览 / 迭代（同效果看一眼） | `224`，4~8 帧（≈0.2~0.6 s）                               |
| 正式出点云                      | `512`，10~16 帧（≈2~3.5 s，点数 1.5M~2.4M）               |
| 纯网页无 AR 位姿                | 任意尺度，需「标尺校准」                                  |
| 有 AR 位姿                      | 服务器自动对齐到米制（见 `docs/ARCHITECTURE.md` 第 6 节） |

> 速度瓶颈在 ViT 编码，与帧数近似线性；分辨率影响约平方级（512 是 224 的 ~3.4 倍时长）。
